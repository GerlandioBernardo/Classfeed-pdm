# Classfeed

## Roda roda

1. **Defina as variáveis de ambiente** no arquivo `.env` na raiz do projeto:
   - `BACKEND_URL`: URL do backend da aplicação.
   - `BACKEND_TIMEOUT`: Tempo limite para requisições ao backend.

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o projeto**:
   ```bash
   npm run start
